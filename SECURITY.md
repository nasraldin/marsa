# Security policy

## Report a vulnerability privately

**Private reporting channel pending.** The project owner will publish the reporting channel here once it is configured. Keep vulnerability reports and related details off public issues, pull requests, and discussions.

A report should include the affected version or commit, the affected component, the potential impact, and enough detail for maintainers to reproduce and verify the issue. Redact credentials, personal data, and sensitive paths from supporting material.

## Response and disclosure

The project targets initial triage within one working day of receiving a relevant report. Maintainers coordinate remediation and disclosure privately and identify fixed CVEs in release notes. See the [vulnerability response plan](docs/11-security.md#vulnerability-response) for the response targets.
