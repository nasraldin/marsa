# دليل استخدام مرسى

[English](../README.md) · [إعداد الوكلاء](agents.md)

## التثبيت والتشغيل

يتطلب مرسى جهاز Mac بمعالج Apple silicon ونظام macOS 27 أو أحدث. نزّل ملف DMG الموقّع من صفحة إصدارات المشروع باستخدام المتصفح، ثم افتحه واسحب مرسى إلى مجلد التطبيقات. افتح مرسى من Finder واتبع تأكيد الفتح الأول المعتاد إذا ظهر. إذا منع macOS فتح التطبيق، فتحقّق من مصدر التنزيل ونزّل نسخة جديدة من صفحة إصدارات المشروع.

افتح **الجهاز** وشغّل المحرّك. انتظر حتى تصبح حالته **جاهز** قبل تشغيل حاوية. يمكنك تغيير اللغة والمظهر من **الإعدادات ← عام**. يتبع التطبيق مظهر macOS عند اختيار **حسب النظام**.

## استخدام Docker

سجّل سياق `marsa` من **الإعدادات ← Docker**. يضيف ذلك السياق إلى إعدادات Docker الخاصة بحسابك ويحافظ على السياق المحدد حاليًا. حدّد السياق صراحةً عند استخدام أكثر من محرّك.

```sh
docker --context marsa run --rm hello-world
```

إذا لم يكن أمر Docker متاحًا في `PATH`، فاستخدم العميل المرفق.

```sh
/Applications/Marsa.app/Contents/Resources/bin/docker --context marsa run --rm hello-world
```

يتوفر أمر مرسى في `/Applications/Marsa.app/Contents/MacOS/marsa`. استخدم الاسم `marsa` في الأمثلة أدناه إذا كنت قد أضفته إلى `PATH`. يعرض الأمر `marsa env` إعداد متغير الصدفة لمقبس Docker الخاص بمرسى. إذا عُيّن `DOCKER_CONTEXT` في الصدفة، فله الأولوية على `DOCKER_HOST`.

تعرض شاشات **الحاويات** و**الصور** و**وحدات التخزين** و**الشبكات** موارد المحرّك المتصل. تظهر مشاريع Docker Compose عندما تكون لحاوياتها وسوم Compose. إذا طلب التطبيق اختيار ملف Compose لإجراء معيّن، فاختر الملف الخاص بالمشروع. يحتفظ إجراء الإيقاف والإزالة بوحدات التخزين المسماة افتراضيًا. تتطلب إزالتها كتابة اسم المشروع.

يبحث مرسى عن محرّك Docker محلي ويعرض موارده في صفحات **الحاويات** و**الصور** و**وحدات التخزين** و**الشبكات** و**Compose**. توضّح شارة المصدر المحرّك. الموارد الخارجية للقراءة فقط. استخدم سياق Docker الخاص بالمحرّك لتشغيل أعباء عمله. يعرض قسم **Docker** في الإعدادات المقبس المكتشف ويتيح إعادة البحث.

## مشاركة المجلدات

أضف مجلد المشروع من **الإعدادات ← المشاركة** واختر القراءة فقط أو القراءة والكتابة. إذا طلبت حاوية مجلدًا آخر على الجهاز، فراجع المسارات الفعلية واختر **مشاركة لهذه الجلسة** أو **مشاركة دائمة** أو **رفض**. قد تتاح المشاركة الثابتة الجديدة عند التشغيل التالي للجهاز الافتراضي. احفظ عمل الحاويات قبل اختيار إعادة تشغيل المحرّك.

يحمي مرسى مجلدات بيانات الاعتماد، ومنها `~/.ssh` و`~/.aws` و`~/.gnupg` و`~/.kube` و`~/.docker`، بالإضافة إلى مجلد بياناته الخاص. لا تتيح مشاركة المجلد الأب الوصول إلى مجلداته المحمية. إذا أبلغ Docker بأن مسار الجهاز خارج المجلدات المشتركة، فشارك مجلد المشروع المقصود أو راجع الطلب المعلّق باستخدام `marsa share approvals`.

## الشبكات وVPN

يفضّل الوضع **تلقائي** في **الإعدادات ← الشبكة** استخدام NAT الأصلي وقد يستخدم شبكة مساحة المستخدم إذا تعذّر الاتصال عبر NAT. راجع الوضع النشط في الإعدادات أو باستخدام `marsa network status`. يسري الوضع المحفوظ عند تشغيل المحرّك في المرة التالية. أبقِ إعدادات VPN وجدار الحماية المعتادة أثناء تشخيص المشكلة.

إذا تعذّر حل اسم، فتحقّق أولًا من اتصال جهاز Mac وإعدادات DNS لديه. يمكنك حفظ عناوين DNS ونقاط وكيل HTTP أو HTTPS من دون بيانات اعتماد في إعدادات الشبكة. راجع الأثر قبل تطبيق تغييرات الوكيل، فقد يؤدي تطبيقها إلى إعادة تشغيل المحرّك ومقاطعة الأعمال الجارية.

استخدم `localhost` على جهاز Mac للمنافذ المعاد توجيهها عندما يدعم الإصدار إعادة التوجيه. قد يتعذّر ربط المنفذ لأنه مستخدم أو لأن macOS رفض الربط. اختر منفذًا غير مستخدم لا يتطلب امتيازات، مثل `8080`. لا يضمن نشر المنفذ على جميع العناوين إتاحته من جهاز آخر. يعتمد الوصول عبر الشبكة المحلية على خيارات الإصدار.

## الموارد وتنظيف القرص

يمكنك تعديل عدد المعالجات والذاكرة وحدّ القرص من **الجهاز** أو **الإعدادات ← الموارد**. تسري التغييرات التي تتطلب إعادة التشغيل عند تشغيل المحرّك في المرة التالية. احفظ عمل الحاويات الجارية قبل إيقاف المحرّك.

في **القرص والتنظيف**، راجع الفئات وعاين العناصر المرشّحة للتنظيف. يظل الحذف الجماعي غير متاح في النسخة الحالية إلى حين التحقق من حذف العناصر المحددة بدقة. استخدم **استرداد المساحة** لإعادة الكتل الفارغة إلى macOS. قد تختلف المساحة الملحوظة على الجهاز عن تقدير المعاينة.

## الاختلافات عن Docker Desktop

| ما قد يظهر | ما يمكنك فعله |
| --- | --- |
| لا يتوفر للصورة إصدار Linux ARM64، أو يعرض Docker رسالة `no matching manifest for linux/arm64`. | اختر وسمًا يشتمل على `linux/arm64`. يشغّل مرسى أعمال Linux على ARM64 ولا يحاكي `linux/amd64`. |
| رُفض ربط المجلد لأن مسار الجهاز خارج المجلدات المشتركة. | راجع الطلب من **الإعدادات ← المشاركة**. شارك مجلد المشروع المطلوب فقط. تظل المسارات المحمية مستثناة. |
| يمكن الوصول إلى المنفذ المنشور من جهاز Mac لكن يتعذّر الوصول إليه من جهاز آخر. | تحقّق من خيارات إعادة التوجيه والشبكة المحلية التي يتيحها الإصدار. استخدم `localhost` للاتصال المحلي. عدم إتاحة الشبكة المحلية لا يشير إلى فشل المحرّك. |
| يرفض البناء المحلي لمنصات متعددة هدفًا غير مدعوم، أو ينتج صور ARM64 فقط. | ابنِ لمنصة `linux/arm64` محليًا. اختر أداة بناء عن بُعد تدعم البنية الأخرى عند الحاجة. |

تظل أوامر Docker ومخرجات سطر أوامر مرسى باللغة الإنجليزية عند اختيار العربية لواجهة التطبيق. [الاختلافات المعروفة والمقصودة](../../09-cli-and-docker-compat.md#known-and-intended-differences)

## التحديث واستكشاف المشكلات

من **الإعدادات ← التحديثات**، راجع قناة الإصدار وتحقّق من التحديثات إذا كان الإصدار يدعم هذه الميزة. إذا لم تتوفر التحديثات داخل التطبيق، فنزّل الإصدار الموقّع التالي من صفحة إصدارات المشروع.

إذا توقف المحرّك أثناء بدء التشغيل، فافتح **الجهاز** لمعرفة المرحلة التي تعذّرت وأعد المحاولة. يعرض `marsa status` الحالة الحالية ويعرض `marsa logs` السجلات الأخيرة. ينشئ `marsa diagnose` ملف تشخيص خاصًا ويطبع مساره. افحص الأرشيف قبل مشاركته. إذا اتصل Docker بمحرّك آخر، فتحقّق من السياق النشط ومتغيّري `DOCKER_CONTEXT` و`DOCKER_HOST`.

## إلغاء التثبيت

1. انسخ بيانات العمل التي تريد الاحتفاظ بها. أوقف المحرّك وعطّل **بدء التشغيل عند تسجيل الدخول** من **الإعدادات ← عام**.
2. أغلق مرسى وانقل `Marsa.app` من مجلد التطبيقات إلى سلة المهملات.
3. أزل سياق Docker المسمّى `marsa` إذا كنت قد سجّلته. إذا كان هو السياق النشط، فانتقل أولًا إلى السياق الذي تريد استخدامه.
4. افتح `~/.marsa` في Finder من **انتقال ← الانتقال إلى مجلد**. انقله إلى سلة المهملات فقط إذا كنت تريد حذف وحدات التخزين والصور والإعدادات والأذونات المحلية. أزل أي روابط أو إدخالات في `PATH` أضفتها لمرسى.

يتطلب أمر الاستعادة إلى إعدادات المصنع تأكيدًا بالكتابة لأنه يحذف بيانات العمل أيضًا. يستخدم هذا الأمر لإعادة ضبط مرسى بينما لا يزال التطبيق مثبتًا.
