# إعداد عميل MCP لمرسى

[English](../agents.md) · [دليل الاستخدام](README.md)

اضبط مضيف MCP محليًا موثوقًا لتشغيل مرسى عبر الإدخال والإخراج القياسيين. اختر معرّفًا للعميل ومسارًا مطلقًا للمشروع. إذا كان المضيف يستخدم JSON لإعداد خوادم MCP، فأضف الإدخال التالي إلى قائمة الخوادم بحسب توثيق المضيف.

```json
{
  "command": "/Applications/Marsa.app/Contents/MacOS/marsa",
  "args": ["mcp", "--client-id", "local-dev", "--project", "/Users/you/projects/example"]
}
```

استبدل مسار المشروع بمسارك. تمنح الخدمة جسر MCP صلاحية مقيّدة عند بدء الاتصال. لا تضف مقبس Docker أو اتصال المالك بالخدمة إلى إعداد الوكيل.

1. شغّل مرسى وصِل عميل MCP. اطلب منه قراءة حالة المحرّك أو عرض الحاويات الجارية.
2. افتح **النشاط** أو نفّذ `marsa agents list` لعرض العملاء المسجّلين والأذونات النشطة والطلبات المعلّقة.
3. إذا تطلّبت عملية مدعومة الموافقة، فراجع العميل والمشروع والعملية والموارد المتأثرة. اختر الموافقة مرة واحدة أو الرفض. يتوفر إذن دائم للمشروع للعمليات المؤهلة فقط. تتطلب إجراءات الإتلاف والإجراءات التي تؤثر على الجهاز المضيف موافقة مستقلة إذا كان الإصدار يدعمها.
4. ألغِ الإذن من **النشاط** أو نفّذ `marsa agents revoke GRANT` وأكّد الإذن المعني. قد تنتهي صلاحية الطلب المعلّق أثناء مراجعته.

تتوفر عمليات القراءة في التنفيذ الحالي. تتطلب عمليات الكتابة الموافق عليها تحقّقًا دقيقًا من هوية العمل قبل أن ينفّذها مزوّد العمليات بأمان. إذا رُفضت عملية كتابة، فنفّذها بنفسك في مرسى أو Docker. لا تتجاوز موافقة الوكيل حماية المجلدات أو سياسة تفويض المحرّك. [درجات الصلاحية وآلية الموافقة](../../10-mcp-server.md#permission-tiers)
